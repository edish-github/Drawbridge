# Synthetic vendor pack

Every vendor, document, questionnaire answer and certificate in this directory is synthetic
and was generated for this project. No real company is named, described or implied. Any
resemblance to an existing organisation is unintended.

The pack exists so that every demo beat is reproducible: a judge can clone the repository,
run `make seed`, and watch the same findings appear.

## The three hero vendors

| Vendor | Tier | Role | What it must produce |
|---|---|---|---|
| [cleancloud](cleancloud/) | 2 | control | a clean run; Trust Score ≥ 80; band approve |
| [datadynamo](datadynamo/) | 1 | contradictor | an `access_control` contradiction citing a retrieved chunk from the exception notes; an expired certificate caught by a deterministic check; band conditional |
| [nimbuswrite](nimbuswrite/) | 1 | adversary | screening blocks the planted payload; Adversarial Conduct flag; −25 trust points; forced escalation; an unreviewed fourth-party model provider |

Filler vendors are generated by `scenarios/seed.py` so the queue shows ten to twelve reviews
running concurrently rather than one system handling one review.

## Each vendor folder contains

- `profile.json` — vendor facts and the contact persona
- `questionnaire_answers.json` — the answers, with the reply schedule that drives
  time-compressed delivery
- `evidence/` — an audit-report-style document, certificates, policies
- `expected.json` — the assertions the scenario tests check

## The planted payload

`nimbuswrite/evidence/security-overview.md` contains a deliberately planted
prompt-injection payload. Its exact location, its contents and the reason it is there are
documented in [nimbuswrite/README.md](nimbuswrite/README.md).

[injection-corpus](injection-corpus/) holds the variant set used to measure the screening
defence rather than to demonstrate it. Its README states the same thing in its first line.

Both are test fixtures for this project's own defences. They are obviously synthetic, mild,
and use only publicly documented technique classes.
